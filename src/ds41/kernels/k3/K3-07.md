# K3-07: paired-query sparse attention

This variant has no device scratch buffers, allocation/free calls, events, host
synchronization, default-stream work, or persistent mutable state. Every call
launches one kernel on the supplied stream. Concurrent calls and graph replays
have independent CTA-local state.

For `m > 1`, a CTA owns four heads from each of two tokens and 128 output
dimensions. It reads sixteen index slots per token. If the two sixteen-slot
lists are exactly equal and contain only window rows or negative slots, the
CTA loads one KV tile and fills all eight tensor-core head columns with both
tokens. The equality check uses the actual index values, not list positions.
Otherwise the tile is the concatenation of the two lists, and the probability
matrix is block diagonal: each token attends only to its own sixteen slots.
Duplicates, differently ordered windows, negative indices, arbitrary compressed
indices, partial tiles, and a missing second token in an odd-sized batch are
handled without assumptions about the fixed acceptance test's list generator.

For `m == 1`, a CTA owns four heads and 64 output dimensions, traversing 32 index
slots at a time. This exposes 128 CTAs for the single-token case.

Both paths use BF16 `m16n8k16` tensor cores for QK and PV and FP32 accumulation.
The running maximum starts at `-1e30`, excludes the sink, and ignores negative
index slots. The softmax denominator uses unrounded P. P is converted to BF16
before PV. FP32 numerators are rescaled when the running maximum changes. The
sink is added once, at final normalization. This is the online softmax rounding
explicitly permitted by the K3 spec.

## Checks performed in the cloud

- CUDA 12.8, C++17, compile-only for sm_86, sm_89, and sm_120: passed
- `python src/ds41/kernels/k3/verify_multiquery.py`: 56 CPU model cases passed;
  worst modeled relative L2 error was 0.00213208 (limit 0.003)
- CPU cases cover m=1..8, n_idx=0..1024, shuffled common windows, independent
  lists, duplicated compressed indices, negative holes, all-empty lists,
  partial tiles, and odd token counts
- Both template instantiations statically require at most 48 KiB shared memory
- Only CI-FILES are changed; interface and acceptance test are unchanged

The CPU model does not emulate exact tensor-core accumulation order or run
CUDA. GPU parity, graph capture, CMake integration, and timings must be checked
by the repository's RTX 4090 queue. No GPU result or performance claim is made.
