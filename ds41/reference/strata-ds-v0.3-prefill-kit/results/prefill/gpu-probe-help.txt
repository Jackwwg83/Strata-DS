Optional real-weight / synthetic-activation EXL3 component probe. Requires a
locally installed, trusted ExLlamaV3 with the MUL1 interface read in PF-S03,
PyTorch/CUDA, safetensors and a subset audit generated by this kit. It does
NOT install code, rent a machine, download weights, change drivers, qualify
the whole model, or turn a component timing into a model throughput.

options:
  -h, --help            show this help message and exit
  --checkpoint CHECKPOINT
  --files-list FILES_LIST
                        small explicit JSON shard list sufficient for selected
                        complete bundles
