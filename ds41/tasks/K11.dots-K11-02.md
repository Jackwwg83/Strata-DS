# K11-02: plain AVX2 K3 prepared-row specializations

Base: `origin/feature/ds41` at `21d229a10df81c89a89b4db8ad6fd69f1a9c68a8`.
Branch: `task/K11/dots-K11-02`.

## Change

- Route integer 3-bit weights on the existing AVX2 tier to separate kernels for
  one, two, three, or four prepared rows. Row-count decisions move outside the
  tile loop, allowing fixed accumulators instead of runtime-indexed storage.
- For a 16-bit state window with right shift at most 16, the high word's
  `a << (32 - shift)` contributes nothing after `& 0xffff`; omit that gather,
  shift, and OR. Crossing windows retain the vendor extraction.
- Retain the existing unsigned byte-pair sums, signed-16 activation multiply,
  int32 accumulation order, correction, and FMA output. Input quantization,
  wide-row preparation/folding, threading, prefetch policy, all other bitrates,
  scalar fallback, and all AVX-512 tiers are unchanged.
- New implementation is isolated in `strata_avx2_k3_rows.h`; marked vendor-source
  changes only include it and select its four specializations. `moe_mul1.h`
  and the fixed acceptance test are unchanged.

## Performance evidence and limits

Alternating A/B synthetic direct-kernel tests were pinned to one cloud CPU and
measured with `CLOCK_THREAD_CPUTIME_ID`, with 21 retained samples per variant.
Two runs of the full 5120-by-2304 gate shape had new/old m1 ratios 0.876 and
0.863. Other row counts/shapes were noisy, including occasional regressions;
these data do not establish queue speed or the required 3% acceptance margin.
The benchmark is included for reproducibility, not as a replacement score.
Only the fixed real-golden queue can decide accuracy and ranking. Full engine
link and target-machine performance remain queue checks.

Independent frozen-source review also passed 905,216 guarded bit-state checks,
16,711,680 exhaustive signed pair products, and 93,312 bitwise outputs across
432 matrices with one through eight prepared rows. All 819 AVX-512 band/tile
symbols had identical normalized disassembly; address-only relocations differ.
The new kernels contain no EVEX, ZMM, or high-YMM instructions.


## Iteration 2: combine with the merged AVX-VNNI control

The queue passed the original `68aecf5` candidate at score_us 5743, us_m1 3360,
us_m8 19064, with the original accuracy errors unchanged. K11-01 was selected
as the new control at score_us 5264, us_m1 3181. The reviewer requested keeping
that default path while testing this older-CPU/plain-AVX2 improvement separately.

This iteration merges current `feature/ds41` at
`a5918af3bebbdf646fba949668e0d3ff92ec74d4` into the existing K11-02 branch,
preserving both parents and the existing published history. The only merge
conflict was the two adjacent implementation includes; both are retained.
`strata_avxvnni.h`, hardware detection, ISA caps, input preparation, and the
higher-priority AVX-VNNI dispatch are identical to the current control.

Integer K3 AVX-VNNI hardware continues to use K11-01. Setting
`EXL3_MOE_CPU_MAX_ISA=avx2`, or running on hardware without AVX-VNNI/AVX-512,
selects the K11-02 plain-AVX2 specialization. No new ISA or math change is added
in iteration 2, and no performance gain for the combined default path is claimed.

Iteration-2 local rechecks: the combined whole vendor translation unit compiled
with GCC 14.2, C++17, `-O3 -pthread`; the fixed acceptance executable linked.
Against the exact merged K11-01 control object, all 96 mixed-rate/wide-row
forward cases were bitwise equal under each of default, avx2, avxvnni, bw,
vnni, vbmi, and scalar selections (672 cases, 774,144 float outputs total).
Source identity checks verify that removing the reviewed K11-02 include and
plain-AVX2 dispatch case reproduces the current feature source byte-for-byte.
The two implementation headers retain their previously reviewed content.

The combined full H5120/F2304, 32-expert, top-k=6 forwards at m1/m8 were also
bitwise equal under default, forced AVX2, and forced AVX-VNNI selection. An
actual-object ISA probe (only exposing the existing private ISA variable in a
scratch object) matched the merged control under every cap: scalar=0, avx2=1,
avxvnni=2, bw=3, vnni=4, vbmi=5; this AVX-512 host defaults to vbmi=5.

Independent iteration-2 review found no blocker: all 824 AVX-512, AVX-VNNI,
and detection symbols match the merged K11-01 control's normalized instructions;
all four plain-AVX2 specialization symbols match the previously reviewed K11-02
object. The reviewer independently verified the seven ISA-mode mixed/wide dumps
and six full-shape dumps. Real queue acceptance of the combined commit is pending.
