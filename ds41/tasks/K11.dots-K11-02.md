# K11-02: plain AVX2 K3 prepared-row specializations

Base: `origin/feature/ds41` at `21d229a10df81c89a89b4db8ad6fd69f1a9c68a8`.
Branch: `task/K11/dots-K11-02`.

## Change

- Route integer 3-bit weights on the existing AVX2 tier to separate kernels for
  one, two, three, or four prepared rows. Row-count decisions move outside the
  tile loop, allowing fixed accumulators instead of runtime-indexed storage.
- For a 16-bit state window with right shift at most 16, the high word's
  `a << (32 - shift)` contributes nothing after `& 0xffff`; omit that gather,
  shift, and OR. Crossing windows retain the vendor extraction.
- Retain the existing unsigned byte-pair sums, signed-16 activation multiply,
  int32 accumulation order, correction, and FMA output. Input quantization,
  wide-row preparation/folding, threading, prefetch policy, all other bitrates,
  scalar fallback, and all AVX-512 tiers are unchanged.
- New implementation is isolated in `strata_avx2_k3_rows.h`; marked vendor-source
  changes only include it and select its four specializations. `moe_mul1.h`
  and the fixed acceptance test are unchanged.

```sh

  third_party/exllamav3_moe/tests/strata_avx2_k3_test.cpp -o /tmp/k11-k3-test
```

object and once against the candidate object; compare the output files with
`cmp`. The host's AVX2 path is forced with `EXL3_MOE_CPU_MAX_ISA=avx2`.

## Performance evidence and limits

Alternating A/B synthetic direct-kernel tests were pinned to one cloud CPU and
measured with `CLOCK_THREAD_CPUTIME_ID`, with 21 retained samples per variant.
Two runs of the full 5120-by-2304 gate shape had new/old m1 ratios 0.876 and
0.863. Other row counts/shapes were noisy, including occasional regressions;
these data do not establish queue speed or the required 3% acceptance margin.
The benchmark is included for reproducibility, not as a replacement score.
Only the fixed real-golden queue can decide accuracy and ranking. Full engine
link and target-machine performance remain queue checks.

Independent frozen-source review also passed 905,216 guarded bit-state checks,
16,711,680 exhaustive signed pair products, and 93,312 bitwise outputs across
432 matrices with one through eight prepared rows. All 819 AVX-512 band/tile
symbols had identical normalized disassembly; address-only relocations differ.
The new kernels contain no EVEX, ZMM, or high-YMM instructions.
