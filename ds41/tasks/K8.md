## What it computes

Interface: `include/strata/ds41/kernels/k8_router.hpp` (`router_topk`). Every layer routes each token to 6 of 384
experts (`Gate.forward` in `ds41/proto/ref/model.py`):

1. `logit_e = x . w_e` in FP32 (BF16 inputs; 384 x 5120 weight).
2. `s_e = sqrt(softplus(logit_e))`, softplus(v) = v for v > 20, else log1p(exp(v)).
3. Pick the 6 largest `s_e + bias_e` (ties: lower id), in descending order.
4. `weight_i = s_i / (sum of the 6 s + 1e-20) * 1.5`.

## Acceptance (`src/ds41/tests/k8_router_test.cu`, fixed)

- Same expert ids in the same order as the reference; weights within relative 1e-5. m in {1, 5, 8}.
- Ranking: `score_us = us_m1 + us_m8/8`.

## Hints

The 3.9 MB weight read dominates: one pass for all m tokens, then a tiny top-6 per token in the same kernel.
Baseline: a GEMV per token plus selection on the host (device-host copies on every call).
